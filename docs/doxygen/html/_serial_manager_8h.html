Descripción detallada

Gestión del puerto serie y despacho de tramas del protocolo UNER.

SerialManager actúa como fachada entre la interfaz gráfica y el stack de comunicación. Encapsula la apertura/cierre del QSerialPort, el watchdog de heartbeat y la traducción entre señales Qt y tramas UNER.
