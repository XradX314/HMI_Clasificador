Descripción detallada

Codificador y decodificador de tramas del protocolo UNER.

Provee métodos estáticos para construir tramas (encoders) y un parser incremental orientado a bytes para decodificar el stream de datos recibido por el puerto serie (decoder).

Uso del decoder

UnerProtocol proto(parent);
connect(&proto, &UnerProtocol::frameReceived, this, &MiClase::onFrame);
proto.feed(datosRecibidos);
