Descripción detallada

LED circular animado que muestra el estado del heartbeat con el MCU.

Recibe eventos de heartbeat mediante onAlive() y actualiza visualmente:

  • Verde (On): heartbeat recibido recientemente (1 s de destello).
  • Gris (Off): sin actividad reciente.
  • Naranja (Timeout): sin heartbeat durante más de 7 s.

El widget también muestra etiquetas de texto con la cantidad de heartbeats recibidos, el intervalo estimado y la hora del último pulso.
