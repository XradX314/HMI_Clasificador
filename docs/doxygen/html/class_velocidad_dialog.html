Descripción detallada

Diálogo flotante para configurar el ancho de la caja de referencia.

Envía el comando 0x62 con un único byte (anchoCaja en cm). El MCU utiliza ese valor para calcular internamente la velocidad de la cinta; no se espera respuesta de vuelta.

Al presionar «Enviar 0x62» se emite la señal requestAnchoCaja.
