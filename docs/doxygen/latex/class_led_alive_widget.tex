\doxysubsection{Descripción detallada}
LED circular animado que muestra el estado del heartbeat con el MCU. 

Recibe eventos de heartbeat mediante \doxylink{class_led_alive_widget_a15e20684ac5fcd32621b94db293458de}{on\+Alive()} y actualiza visualmente:\+
\begin{DoxyItemize}
\item {\bfseries{Verde (On):\+}} heartbeat recibido recientemente (1 s de destello).
\item {\bfseries{Gris (Off):\+}} sin actividad reciente.
\item {\bfseries{Naranja (Timeout):\+}} sin heartbeat durante más de 7 s.
\end{DoxyItemize}

El widget también muestra etiquetas de texto con la cantidad de heartbeats recibidos, el intervalo estimado y la hora del último pulso.
