\doxysubsection{Descripción detallada}
Ventana principal del sistema HMI Clasificador de Paquetes. 

Implementa la capa de presentación completa del HMI. Gestiona:\+
\begin{DoxyItemize}
\item La barra de herramientas de conexión serie.
\item El panel de control (Start/\+\+Stop/\+\+Reset/\+\+Modo ciego/\+\+Trigger).
\item Los paneles de visualización (sensores IR, brazos, contadores, última caja medida).
\item La apertura de diálogos de configuración (calibración, ancho de caja, configuración avanzada de hardware).
\item La propagación de eventos del \doxylink{class_serial_manager}{Serial\+Manager} a la interfaz.
\end{DoxyItemize}

Los temas claro/\+oscuro se aplican mediante hojas de estilo QSS definidas como constantes estáticas al inicio del archivo .cpp.
