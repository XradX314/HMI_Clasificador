\doxysubsection{Descripción detallada}
Diálogo flotante para configurar la calibración del sensor y los brazos. 

Genera y envía el comando 0x63 (7 bytes) con los siguientes campos:\+
\begin{DoxyItemize}
\item calibracion\+[0]\+:\+ distancia del sensor al piso (cm).
\item calibracion\+[1]\+:\+ altura de la caja pequeña (cm).
\item calibracion\+[2]\+:\+ altura de la caja mediana (cm).
\item calibracion\+[3]\+:\+ altura de la caja grande (cm).
\item tolerancia:\+ margen de error permitido (cm).
\item time\+\_\+arm\+\_\+extend:\+ ticks de extensión del brazo (1 tick = 2 ms).
\item time\+\_\+arm\+\_\+retract:\+ ticks de retracción del brazo (1 tick = 2 ms).
\end{DoxyItemize}

Cuando el usuario presiona «\+Enviar 0x63» se emite la señal \doxylink{class_config_dialog_a0e877e11a6fd35cb5ad6cb33dfca5b26}{config\+Applied} con la estructura \doxylink{struct_uner_1_1_calibracion_cfg}{Uner::\+\+Calibracion\+Cfg} rellena.
