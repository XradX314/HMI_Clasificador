\doxysubsection{Descripción detallada}
Gestiona la conexión serie y el ciclo de vida del protocolo UNER. 

Responsabilidades:\+
\begin{DoxyItemize}
\item Abrir y cerrar el QSerial\+Port con los parámetros correctos (8N1).
\item Reenviar bytes recibidos al \doxylink{class_uner_protocol}{Uner\+Protocol} para su decodificación.
\item Mantener el watchdog de heartbeat (timeout 7 s).
\item Exponer métodos de envío tipados para cada comando del protocolo.
\item Emitir señales de alto nivel cuando llegan tramas del MCU. 
\end{DoxyItemize}
