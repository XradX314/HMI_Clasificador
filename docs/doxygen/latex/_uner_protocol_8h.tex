\doxysubsection{Descripción detallada}
Definición del protocolo de comunicación serie UNER y el codificador/\+decodificador de tramas. 

El protocolo UNER es un protocolo binario orientado a tramas que opera sobre UART. Cada trama tiene la estructura:\+


\begin{DoxyCode}{0}
\DoxyCodeLine{[\ \textcolor{charliteral}{'U'}\ \textcolor{charliteral}{'N'}\ \textcolor{charliteral}{'E'}\ \textcolor{charliteral}{'R'}\ |\ len\ |\ \textcolor{charliteral}{':'}\ |\ cmd\ |\ payload\ (n\ bytes)\ |\ checksum\ ]}

\end{DoxyCode}


donde {\ttfamily len} = 1 + n + 1 y {\ttfamily checksum} es el XOR de todos los bytes anteriores al propio checksum.
