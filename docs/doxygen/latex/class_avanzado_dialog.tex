\doxysubsection{Descripción detallada}
Diálogo flotante con cuatro secciones de configuración de bajo nivel. 

Cada sección tiene su propio botón «\+Enviar» y emite una señal independiente para que \doxylink{class_main_window}{Main\+Window} pueda reenviar el comando al MCU:\+


\begin{DoxyTable}{3}{}{}{1}
\SetCell{c,bg=\tableheadbgcolor,font=\bfseries}Sección  &\SetCell{c,bg=\tableheadbgcolor,font=\bfseries}CMD  &\SetCell{c,bg=\tableheadbgcolor,font=\bfseries}Señal emitida  \\
HC-\/\+SR04  &0x64  &\doxylink{class_avanzado_dialog_a08928e4ca6237830a56cff0815ac6642}{send\+Hcsr04()}  \\
Servo SG90  &0x65  &\doxylink{class_avanzado_dialog_a21888bf213fcbb333ba72431f8efdab3}{send\+Sg90()}  \\
Debounce IR  &0x66  &\doxylink{class_avanzado_dialog_a9c2b45f14d55619bd1cd71825c9088db}{send\+Ir\+Debounce()}  \\
Timers/\+\+Cajas  &0x67  &\doxylink{class_avanzado_dialog_a3a408184a866a425e300bb5c4d7f7bec}{send\+Timers()}  \\
\end{DoxyTable}


El diálogo es desplazable verticalmente para acomodar todos los campos.
