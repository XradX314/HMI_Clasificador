\doxysubsection{Descripción detallada}
Gestión del puerto serie y despacho de tramas del protocolo UNER. 

\doxylink{class_serial_manager}{Serial\+Manager} actúa como fachada entre la interfaz gráfica y el stack de comunicación. Encapsula la apertura/\+cierre del QSerial\+Port, el watchdog de heartbeat y la traducción entre señales Qt y tramas UNER.
